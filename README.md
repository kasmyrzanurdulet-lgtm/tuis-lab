# TUIS LAB

Қазақстан оқушыларына арналған математика және информатика білім кеңістігінің интерактивті прототипі.

## Мүмкіндіктер
- Оқушы/мұғалім демо кабинеттері, қазақ тіліндегі бейімделетін интерфейс.
- Білім диагностикасы, тапсырмалар, қате тақырыптары және жеке оқу жолы.
- Сынып аналитикасы мен график, сынып коды, көмек сұраулары.
- Демо күйі браузердің localStorage қоймасында сақталады.

## Технологиялар
React, TypeScript, Vite, Lucide React, Recharts. Supabase конфигурацияланбаған; аутентификация мен деректер — жергілікті демо.

## Іске қосу
`npm install`, `npm run dev`. Өнімдік жинақ: `npm run build`; алдын ала қарау: `npm run preview`.

## Демо аккаунттар
Кіруде «Оқушы» немесе «Мұғалім» рөлін таңдап, кез келген email және кемінде 6 таңбалы құпиясөз енгізіңіз. Демо оқушы: `student@tuislab.kz`; мұғалім: `teacher@tuislab.kz`. Парольдер серверде сақталмайды; бұл нақты қауіпсіз аутентификация емес.

## Supabase және GitHub
`.env.example` мәндерін жергілікті `.env` файлына енгізуге болады. Supabase Auth, серверлік рөл тексеруі және RLS әлі қосылмаған. `.env` файлдарын GitHub-қа қоспаңыз. Vercel-де құрастыру командасы `npm run build`, шығару бумасы `dist`.

## Демо шектеулері
Кейбір сынып, аналитика және тарих мәліметтері «Демо дерек» ретінде берілген. Еркін код орындалмайды. Көмек сұрауы мен тапсырмалар браузерде сақталады.
